# 📈 AI自動売買システム (マルチエージェント・アーキテクチャ)

本システムは、日本の主要株（TOPIX）を対象に、**完全自動で「銘柄探し」「戦略最適化」「取引判定」を行う**AIトレーディングシステムです。
スマホからも見やすいWEBダッシュボードを備え、将来的なSBI証券APIやGemini APIの連携を見据えた高度な設計となっています。

---

## 🚀 1. 初期設定 (インストール)

システムを動かすために必要なツール（パッケージ）をインストールします。
ターミナル（Windowsの場合はPowerShellやコマンドプロンプト、Macの場合はターミナル）を開き、以下のコマンドを実行してください。

```bash
pip install -r requirements.txt
```
*(※エラーが出る場合は `pip install yfinance sqlalchemy pandas streamlit matplotlib` を実行してください)*

---

## 🤖 2. システムの動かし方 (日々のルーティン)

このシステムは「リサーチ」「運用計画」「執行」の3つのAIがバケツリレーのように情報を渡して動きます。
1日1回（市場が閉まった夕方や夜など）に、以下の順番でコマンドを実行してください。

### ① リサーチAI（銘柄の自動スクリーニング）
市場全体から、直近で勢いがあり（モメンタム）、出来高が多い「今勝負すべき5銘柄」を自動で選び出します。
```bash
python screener.py
```
*(※結果は `portfolio.json` に保存されます)*

### ② 運用AI（バックテストと戦略の最適化）
①で選ばれた5銘柄に対し、それぞれ過去のデータを使って「どの移動平均線の組み合わせが一番勝てるか」を計算し、学習します。
```bash
python simulation.py
```

### ③ 取引執行AI（実際のトレード判定）
現在のあなたの「資金（余力）」と、②で学習した「勝てるルール」を照らし合わせ、本日の最新株価から**「買う」「売る」「何もしない（様子見）」**を判定・実行します。
```bash
python trading.py
```

## 📱 3. アプリ（ダッシュボード）の開き方

ご自身の成績（保有株、含み損益、過去のトレード履歴、AIからの分析レポートなど）を確認するためのWEB画面です。

**Windowsの場合:**
フォルダの中にある `start_app.bat` をダブルクリックするだけで、全自動でブラウザが立ち上がりアプリが開きます。（ターミナルを開いてコマンドを打つ必要はありません！）

**Mac / Linuxの場合:**
ターミナルを開き、以下のコマンドを実行するか、`start_app.sh` を実行してください。
```bash
python3 -m streamlit run app.py
# または
./start_app.sh
```

### 🌟 スマホ（iPhone/Android）からアプリを見る方法
このアプリは「ローカルネットワーク（ご自宅のWi-Fi）」上で動いています。
パソコンと**同じWi-Fi**に繋がっているスマホであれば、アプリにアクセスできます。

1. パソコンで `python -m streamlit run app.py` を実行した際、ターミナルに以下のような文字が表示されます。
   ```text
   Network URL: http://192.168.1.5:8501
   ```
2. スマホのブラウザ（SafariやChrome）を開き、この `Network URL` の数字（例：`192.168.1.5:8501`）をアドレスバーに入力するだけで、スマホから綺麗なアプリ画面を見ることができます！

## ⚙️ 4. 詳細な設定

### 余力（アカウント残高）の設定
ダッシュボード画面（`app.py`）の上部に「余力の設定 / 入金」というボタンがあります。
ここからご自身のシミュレーション用の初期資金（例：1,000,000円など）を入力・更新してください。システムはこの余力の範囲内でしか株を買いません。

### Gemini APIキーの入力 (SaaS連携用)
ダッシュボード画面の**左側のメニュー（サイドバー）**に、Google Gemini APIキーを入力する欄があります。
（※スマホの場合は左上の「＞」ボタンを押すとメニューが開きます）
ここにキーを入力すると、今後のアップデートでAIがより高度なニュース分析や反省レポートを書くようになります。

## 🛠️ システムの仕組みと制限事項
*   **データソース**: `yfinance` を使用し、1日1回の終値データを基準に動いています（完全なミリ秒単位のリアルタイムではありません）。
*   **信用取引**: 将来のアップデートを見据え、データベースは現物・信用買い・信用売りに対応していますが、現在は「現物買い」を基本としています。
*   **API連携**: 現在の取引はすべて「ペーパートレード（模擬取引）」です。内部的には `broker.py` を通して注文処理を行っており、ここにSBI証券などのAPIを組み込むことで、本番の現金を使った全自動取引へ移行できます。
